Show the onman quick-reference card.

| Command | What |
|---|---|
| `/onman` | Activate at default level (full) |
| `/onman lite` | Light compression — ~30% tokens dropped |
| `/onman ultra` | Maximum compression |
| `/onman wenyan[-lite\|-ultra]` | Classical Chinese compression |
| `/onman off` | Deactivate |
| `/onman-commit` | Terse commit message |
| `/onman-review` | One-line review findings |
| `/onman-compress <file>` | Compress a Markdown file |
| `/onman-stats` | Lifetime token-savings |

Natural language also works: "turn on onman", "stop onman", "normal mode".

Code, commits, security warnings: onman drops out automatically.
